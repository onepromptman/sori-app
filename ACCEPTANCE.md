# Acceptance cases

Use a disposable state directory and fictional inputs. Status records the
Windows source-checkout review environment; live services and packaged desktop
delivery need separate checks.

## Offline first run

Prerequisites: Python 3.11, uv and a checkout. In PowerShell at the checkout:

```powershell
uv venv --python 3.11
uv pip install -r requirements-app.txt
uv pip install pytest==9.0.3
$env:SORI_HOME = Join-Path $env:TEMP 'sori-acceptance-fictional'
.venv\Scripts\python.exe app.py --selftest
.venv\Scripts\python.exe shows.py list --json
.venv\Scripts\python.exe settings.py show --json
.venv\Scripts\python.exe -m pytest -q
```

Expected for an empty state directory: selftest reports installed backends,
shows is `[]`, and settings show `base.en`, `en`, `studio`, and no API key.
The clean isolated install, selftest, empty list, and settings passed. The
regression suite passed. Dependency installation may
require network; the first Whisper model also needs a download unless cached.
Use a new state directory for each run, not an existing personal library.

Negative cases: `settings.py model unknown` exits 2 and leaves settings
unchanged; corrupt shows JSON is backed up before a new empty store is made;
feed failures make `shows.py check` and headless sweep fail. Automated tests
cover these cases using fictional data and mocked network responses.

## Captions, audio, and desktop

BLOCKED: YouTube captions require network and a video with captions. Run
`python transcribe.py youtube "<fictional-test-video-url>" --out sample.txt`
against an authorized test video; inspect that the transcript preserves the
spoken words and ordering. A video with no matching language must fail clearly.
The local VTT parser regression uses synthetic captions, not a live download.

BLOCKED: the captions-only cloud routine needs an authorized disposable output
repository and a live YouTube subscription. Its auto-training route is blocked
because the sweep does not read the environment API key; see cloud/ROUTINE.md.

BLOCKED: local audio transcription requires an actual test recording and the
chosen Whisper weights. Run `python transcribe.py audio sample.mp3 --out
sample.txt` with an authorized fictional recording, then compare the output
against its known words, including the beginning and end. Repeat without cached
weights and offline: the model load should fail visibly, not claim success.
`base.en` is English-only; select a multilingual model for other languages.

BLOCKED: Windows packaged app and scheduler require the built distribution
and an interactive desktop. The exe opens Sori in the default browser; only
`--window` needs the WebView runtime. Launch it, add an authorized test
feed, check settings, run a sweep, and compare the saved transcript with the
source. Confirm an unavailable feed is reported as a failure. The local
source selftest does not prove the packaged app or scheduler works.

## Claude and other providers

BLOCKED: Claude Code/Cowork plugin routes require their respective client and
an authorized session. Follow the bundled skill instructions with a fictional
transcript, and verify the resulting file names, content and error messages.
The optional Claude API route requires a key and incurs charges. No API call
was made in this review, so availability of the configured default model is
unverified. Other model providers and MCP client integrations are
UNSUPPORTED unless an adapter is added and tested.

## Browser release candidate checks, 2026-11-09

PASS: 237 automated tests, one optional private-font test skipped. Tests use
isolated state and block paid calls. Dependency audit reported no known issues
for the installed Windows Python 3.11 environment.

PASS: real local Whisper transcription of a fictional 29-second speech recording.
The beginning, middle and end matched the known text. A local RSS fixture then
passed through the actual browser source-add, queue, transcription, Library,
timestamped reader and subtitle export. Training without a key failed visibly.
Settings > Stop shut down the test server. No personal library was used.

PASS: the public studio renderer produced an eight-slide editable deck and a
Markdown guide from `examples/learning-demo.json`. The example was authored
for testing, not generated by a live AI request. Its source and outline ship
with the candidate; reproduce it with `train.py --outline`.

UNVERIFIED: paid Anthropic generation, current account/model access, long-episode
quality, live YouTube caption download, Cowork upload, Windows signing and a
clean-machine installation. These are release acceptance limits, not passing
tests. The earlier BLOCKED entries above are retained as historical context.

PASS: the fresh Windows build passed selftest, server startup, empty-state
checks, public theme selection, a local RSS fetch and real audio transcription.
The packaged transcript preserved the test recording's opening, middle and
ending. The app then shut down normally. Package inspection found no optional
private renderer modules or known runtime-data filenames.

## Browser-first distribution

The primary archive is Sori-browser.zip. start-sori.bat (Windows) and
start_sori.py prepare the browser dependency set and open the local app.
No Windows executable, pywebview package or PyInstaller is required.
The default package command does not build an executable. The optional
Windows bundle is requested with --windows-exe.

The browser-first regression suite passes 240 tests with one optional
private-font test skipped. macOS/Linux launchers are provided but have not
received interactive platform acceptance checks.
