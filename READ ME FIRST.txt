START HERE - SORI
=================

1. EXTRACT THE WHOLE ZIP
   On Windows: right-click Sori-browser.zip, then Extract All.
   Open the extracted Sori folder. Do not launch from inside the ZIP.

2. DOUBLE-CLICK "START SORI.bat"
   This is the main Windows start button. If extensions are hidden,
   it may appear as "START SORI" with type "Windows Batch File".
   Python 3.11 or newer is required. Get it from python.org if needed.

3. LEAVE THE SETUP WINDOW OPEN
   First launch downloads components and may take a few minutes.
   Sori then opens in your normal browser. Later launches reuse setup.

Paste a podcast RSS feed, pick an episode and click Transcribe.
Open Library to read the transcript. The first audio job downloads
a speech model. No Sori account or API key is needed for transcription.

FINISHED? Use Settings > Stop. Closing just the tab leaves Sori running.
START AGAIN? Double-click START SORI.bat again.

Keep the app folder beside the launcher. It contains the program files;
you do not need to open it. Your recordings and library are stored separately.

macOS/Linux: run sh "START SORI.command" from this folder. Those platforms
and their local file pickers have not received Windows acceptance checks.

OPTIONAL TRAINING sends transcripts to Anthropic and uses your paid API
credits. Read PRIVACY.md. Review generated material against its source.

OPTIONAL WINDOWS EXE: if you downloaded Sori-win64.zip instead, open
Sori.exe. It bundles Python and starts the same browser app.
