Sori - podcast & YouTube transcripts, free and local
====================================================

START HERE
  Double-click  Sori.exe  (in this folder). It opens in your web
  browser and only runs on your own PC.

  Closing the browser tab leaves Sori running so it can keep
  checking your shows. To shut it down, open Settings and click
  Stop. Double-clicking Sori.exe again reopens it.

  This app is unsigned. Windows may show a security warning.
  Verify the download source and published SHA256 checksum before
  deciding whether to run it.

IMPORTANT
  Keep this whole folder together. Sori.exe needs the "_internal"
  folder beside it. To put it on your Desktop or Start menu,
  right-click Sori.exe -> "Create shortcut" and move the SHORTCUT.
  Moving the exe out on its own makes it fail to start.

WHAT IT DOES
  Add a podcast RSS feed, a YouTube channel (@name), or a playlist,
  and Sori turns new episodes into text. YouTube episodes use the
  video's captions (seconds). Podcast audio is transcribed on your
  own CPU. No account, no API key, no per-minute cost.

  The first audio transcription downloads the Whisper model
  (~150MB, once per machine) - that is the "fetching model" step.

OPTIONAL: daily automatic transcripts
  Double-click  setup-auto-sweep.bat  (in this folder) to register a
  Windows task that checks your shows every morning at 9:03am.
  To remove it later, run in a Command Prompt:
      schtasks /delete /tn "Sori Daily Sweep" /f

OPTIONAL: turn a transcript into a training deck
  This is the one feature that is NOT free - it calls the Claude API
  with your own key and sends the transcript to Anthropic. API charges apply. Add a key under
  Settings -> Training generation. Leave it blank and everything
  else works exactly the same.

YOUR FILES
  Transcripts, settings, and generated decks live in:
      %USERPROFILE%\Sori\
  so they survive replacing or moving the app.
