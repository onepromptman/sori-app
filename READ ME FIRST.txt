Sori - your local browser app
=============================

PRIMARY DOWNLOAD: Sori-browser.zip
Extract the whole folder. Install Python 3.11 or newer from python.org
if needed, including the Python launcher on Windows.

On Windows, double-click start-sori.bat. First launch installs Sori's
browser dependencies in its own environment, then opens your browser.
Keep the launcher running while you use Sori. Later launches reuse setup.
On macOS/Linux, run python3 start_sori.py from this folder.

Paste a podcast RSS feed, choose an episode and click Transcribe.
Your transcript appears in Library. The first audio job downloads a
speech model. Transcription is local and needs no API key.

Closing the browser tab leaves Sori running. Settings > Stop stops it.
Open your launcher again whenever you want to restart.

OPTIONAL WINDOWS PACKAGE: Sori-win64.zip
This bundles Python. If your download contains Sori.exe, opening it
starts the same browser app without a separate Python installation.
Keep its _internal folder beside it. The executable is unsigned;
verify the source and release checksum before choosing to run it.

OPTIONAL TRAINING
Generate Training sends your transcript to Anthropic using your own
API key and paid credits. Auto-train can repeat that for new episodes.
Read PRIVACY.md before using private material. Review generated answers.

Your local library is separate from the downloaded app, normally in
your user folder under Sori. Do not upload that data folder publicly.
