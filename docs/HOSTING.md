# Where Sori runs

Run the browser app on your own computer. It binds to 127.0.0.1 and uses
per-launch authentication. Do not expose it with a public reverse proxy.
The browser tab is an interface to the local Python process; it is not a
hosted service. Keep your computer on during transcription or scheduled work.

The captions-only cloud scripts are a separate advanced route. They require
your own environment and storage, and are not a hosted multi-user Sori product.
Review [cloud instructions](../cloud/README.md) and their validation limits.
Never put your local data folder, credentials or source recordings in a release.
