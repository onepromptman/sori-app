# Upgrading Sori

Stop Sori in Settings before replacing application files. Back up your own Sori
data folder privately. Extract the new browser download into a separate folder
and use its START SORI launcher. Never replace your library with a source ZIP.

For the optional CLI launcher, obtain the new source and run `python sori.py
update` from it. This refreshes the versions pinned in that checkout. It does
not download newer application code or silently upgrade individual dependencies.

Version 3.4 adds optional pipeline bookkeeping and manual slide handoffs.
The local browser remains the main product. Existing transcripts and the four
fictional samples remain usable. The public studio renderer needs no private
component. If an older setting refers to an unavailable theme, select studio
before requesting paid training.
